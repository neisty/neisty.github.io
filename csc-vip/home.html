About the course

Three pillars, one unified curriculum

Each pillar is not a separate skill — they are interconnected aspects of producing valid scientific results.

01

Numerical analysis

Understand the mathematical properties and limitations of computational methods — from integration and interpolation to root-finding and differential equations.

02

Software correctness

Write specifications, design rigorous test suites, and ensure implementations are reliable, testable, and reproducible across platforms and collaborators.

03

Research training

Guided through the full lifecycle — problem formulation to conference dissemination — across chemistry, geophysics, physics, biology, and applied math.

LLM-generated code review

Critically evaluate AI-assisted code for correctness, numerical stability, and hidden assumptions that can corrupt scientific results.

HPC computing (Borah)

Develop and execute code on Boise State's Borah cluster and other high-performance computing environments.

Legacy code validation

Work with real scientific codebases that lack modern testing or verification, learning to validate and trust computational outcomes.

Reproducible workflows

Apply version control, environment management, and documentation practices that make computational results shareable and trustworthy.

Course topics

Eight topic areas

Covering the full breadth of correct scientific programming, ordered by Bloom's taxonomy level.

T1 Editing and running scientific code on Borah / Onyx HPC Remembering
T2 Direct algorithms: numerical integration, differentiation, Gaussian elimination, interpolation Understanding
T3 Iterative algorithms: root-finding, optimization, fixed point methods Understanding
T4 Program specification and requirements for scientific software Evaluating
T5 Testing concepts and test case development Analyzing
T6 Discretization approaches for differential equations Applying
T7 Developing a computational research project from inception to dissemination Creating
T8 Reproducible scientific workflows: version control, environments, documentation Applying

How to join

No prerequisites — all majors welcome

VIP courses require a permission number from the instructor. Here's how to get started.

1

Express interest

Complete the BSU VIP Interest in Registering form at boisestate.edu/vip or contact the instructor directly to request a permission number.

2

Register

Use your permission number to enroll in VIP 200, VIP 400, or VIP 500 for 1 or 2 credits. Each credit equals approximately 40 hours of work per semester.

3

Attend the first meeting

Get oriented to the Borah HPC cluster, meet your cohort of new and returning students, and choose your project focus area.

4

Return and advance

Re-enroll each semester to take on increasing independence, lead sub-teams, and ultimately target regional conference dissemination.
