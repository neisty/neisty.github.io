Course Schedule

A 15-week semester covering formal specification, numerical algorithms, correctness tools, and HPC workflows — culminating in student research projects.

Week Topic Key Content
Week 1 T Course overview, overview of student backgrounds

P Current research interests, project expectations
Week 2 Solving a simple boundary value problem using integral formulation. Introduce need to numerically compute integrals Domain problem, discretization, vectors, summation, measuring errors, accuracy, pseudocode
Week 3 T C implementation of numerical algorithms, running them on Onyx

P Project expectations 		Mapping numerical integration/pseudocode to C code, moving the code to Onyx and running it on Onyx
Week 4 Concept of testing and writing test cases for Week 2 code Definition of a test case, testing frameworks
Week 5 Identifying input/output domain mapping and test case specification; relate back to numerical integration Generalize individual test cases and group them into equivalent class partitions, using propositional logic to formally describe domains
Week 6 T Write more pre/post condition specifications in the test case framework for different numerical code or problems

P Project proposal due (ensure you can compile and run it) 		Introduce more numerical algorithms and practice writing formal spec for them in the form of pre and post conditions
Week 7 P Proposal presentation: describe the code, the problem it solves, why it is important, run/demonstrate it Communication skills, organization, problem solving
Week 8 T Frama-C tool intro and running it on existing code; demonstrate Frama-C spec language, how to run test cases from it Learning a new tool and its interfaces, intro to the spec language
Week 9 T Use Frama-C to write pre/post conditions from Week 6 and run/compile their implementation with Frama-C and generate test cases Mapping pre/post conditions to the Frama-C spec language, debugging incorrect specs, incrementally extending specs
Week 10 T/P Moving code execution to HPC, e.g., Borah Introduction to modern scientific computing workflows
Week 11 P Project progress presentation Communication skills, organization, problem solving
Week 12 T Introduce additional more complex numerical techniques for a different computational problem; compile and run that code

P Potential to incorporate into projects 		More advanced numerical discretization techniques; implications on accuracy and stability
Week 13 Write Frama-C specs for advanced numerical algorithms; additional features of Frama-C, how to use for formal verification Introduce different logics, advanced verification techniques so in the next semester students who continue with the course can build on them
Week 14 Scientific code as a software engineering project GitHub, version control, regression testing, bug report and tracking. Look at examples of scientific computing projects that represent software engineering projects
Week 15 Project presentations Communication skills
End-of-Semester
Project Ideas
  • Take a scientific code and show it is correct using the tools and techniques from the course.
    • Varying levels of difficulty expected based on the enrollment level of the student
    • Code can be legacy, generated by an LLM, or implemented by the student
    • Generate test cases and Frama-C specifications arising from domain knowledge of the problem
  • Proposal: Describe the scientific code, why it is important for the application and for ensuring correctness, and some ideas for how to approach it
  • Assessment: Project will be assessed via a final presentation and submitted code with accompanying specifications
